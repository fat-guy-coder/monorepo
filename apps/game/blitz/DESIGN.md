# Blitz — 等距视角仙侠动作 RPG

> 核心体验：**御剑问道，快意恩仇。** 在等距 3/4 视角的仙侠世界里，用高频操作和丰富技能构筑，一步步探索、变强、揭开故事。
> 一句话：**暗黑式的刷装备 + 怪猎式的固定分图 + 低惩罚死亡 + 大表哥式对话推剧情。**

---

## 一句话定位

等距 3/4 视角的仙侠动作 RPG。玩家在**固定地图**（分块加载）里探索，打怪掉落**永久装备/技能**，死亡在**复活点**复活（低惩罚），通过**触发 NPC 对话**推进剧情。战斗偏动作向：高频操作、强反馈、技能丰富，让玩家有多种方式打怪。

## 为什么是「等距 3/4 + 2D 精灵」，而不是 2D 横版 / 2.5D / 真 3D

| 方案 | 为什么否掉 |
|------|-----------|
| 2D 横版（旧方向） | 只有「左右 + 跳」，走位靠跳跃。仙侠大地图探索需求是「XY 平面走位」，横版装不下 |
| 真 2.5D（多一条 Z 轴） | Z 轴对招式维度几乎无贡献，却要 4-8 方向资产，solo 扛不住 |
| 真 3D 渲染 + 2D 玩法 | 建模/绑骨/贴图是三种里最贵的，偏离纯 2D 美术路线 |
| **等距 3/4 + 2D 精灵** ✅ | 哈迪斯/暗黑/怪猎同款：纯 2D 手绘精灵 + 等距视角 + Y-sort 排序，**看起来立体、实现纯 2D** |

关键点：**「等距 3/4」是 2D 美术 + 视角欺骗，不是真 3D。** 人物画 3/4 视角（能看到全身造型/服装/武器/招式），地面画等距网格，用 Y-sort 决定谁挡谁。仙侠题材最吃「角色造型帅不帅」，等距 3/4 刚好能展示，纯俯视会丢掉。

## 核心循环

```
探索地图 → 打怪 → 掉装备/技能/资源 → 变强 → 推进地图 → 触发剧情
     ↑                                              │
     └────────── 死亡 → 复活点复活（低惩罚）────────┘
```

- **死亡不重开**（非肉鸽）：死亡 → 在最近的复活点复活，已获得的装备/资源**永久保留**
- **死亡惩罚低**（具体待定）：倾向「掉一点资源/经验」而非「掉装备」，避免挫败
- **地图固定**：不做随机地图，玩家按顺序探索一张张分块地图
- **资源是仙侠的灵魂**：修为、灵石、丹药、装备、功法都是可积累的资源

---

## 地图结构（怪猎式分块）

| 特性 | 说明 |
|------|------|
| 结构 | 世界由**多张固定小地图**组成，进入边界触发加载切换到下一张 |
| 连接 | 类似怪猎/黑魂——地图间有明确连接点（山道、洞口、传送阵） |
| 复活点 | 每张地图设 1-2 个复活点（蒲团/石碑/阵眼），死亡在此复活 |
| Boss 区 | 关键地图设 Boss 房，进门即战 |
| 探索节奏 | 固定但非线性——部分地图可解锁捷径回环（回到已探索区） |

> 设计原则：**小地图 + 明确连接 + 回环捷径**，让玩家「一个个探索」有进度感，又不用做无缝大世界。

## 战斗系统（动作向）

### 目标：高频操作 + 强反馈 + 有挑战性

玩家需要频繁做决策（打/躲/挡/放技能），每一次操作都有明确的即时反馈。

### 基础操作

| 操作 | 按键（v0.3 实装值） | 说明 |
|------|-------------|------|
| 移动 | WASD / 方向键 | XY 平面走位（等距八向） |
| 轻击 | J / 左键 | 快、伤害 1、硬直 0.15s |
| 重击 | **按住** K / 右键 蓄力，松开挥出 | 0.75s 蓄满；伤害 2→4；**满蓄破霸体** |
| 闪避 | Space | 无敌帧冲刺，消耗精力 25 |
| 格挡 | **按住** Shift / L | 正面 ±90° 免伤，持续耗精力 + 每次硬挡扣 20 |
| 精准格挡 | 按下格挡键的**那一瞬间**（0.16s 窗口） | 零伤零耗 + 攻击者硬直 1.2s（反击窗口） |
| 技能 1-4 | Q / E / R / F | 主动技能槽位（招式/法术/法宝）← v0.4 |

**三条被实测修正过的操作规则（记下来，别再改回去）：**

1. **格挡时朝向跟随鼠标。** 其余所有状态下朝向 = 移动方向。
   > 原因不是手感，是这个设计在原来的规则下**根本无法成立**：朝向只在移动时更新，
   > 那么「站着举盾 → 敌人绕到背后 → 打不着也转不了身」就变成必然。
   > 扇形格挡和「朝向 = 移动方向」两条规则不能共存，必须选一个让路。

2. **格挡有 0.45s 的精准窗口冷却。**
   > 没有它的话最优解是疯狂连点 Shift，每一下都重开窗口 ——
   > 「精准格挡」退化成没有代价的按键宏，本轮要验的「高频决策」变成「高频无脑按」。

3. **蓄力时可以 50% 速度慢走**（不是原地定身）。
   > 定身会让蓄力在走位为主的战斗里几乎用不出来 —— 敌人一起手你就必须走。

### 资源系统

| 资源 | 上限 | 恢复 | 用途 | 设计意图 |
|------|------|------|------|----------|
| 生命 HP | 成长 | 药品/复活点/修为 | 归零死亡 | 生存压力 |
| 精力 (Stamina) | 固定 | 快速恢复 | 闪避/重击/格挡消耗 | **驱动高频决策**——魂系式资源管理 |
| 真气/灵力 (Mana) | 成长 | 缓慢恢复/击杀 | 技能/法术消耗 | 技能使用的节奏 |

> 精力系统是「操作频率高」的关键：闪避要耗精力，逼玩家在「躲/打/等精力」之间快速切换，而不是无脑翻滚。

### 技能系统（核心卖点：多种方式打怪）

**目标：让玩家构筑自己的打法。** 分三层：

1. **招式（近战武学）**：剑法/刀法/枪法等，改变轻击重击的连段和效果
2. **法术（远程/控制）**：飞剑、剑气、符箓、阵法——远程伤害、AOE、控场
3. **法宝（特殊机制）**：主动释放的强力道具，如飞剑自动索敌、护体罡气、瞬移

| 层 | 举例 | 对应打法 |
|----|------|---------|
| 招式 | 快剑（攻速快）/ 重剑（高伤破防）/ 枪（长手范围）| 近战流派 |
| 法术 | 飞剑索敌 / 剑雨 AOE / 定身符 | 远程/风筝流派 |
| 法宝 | 护体罡气 / 影分身 / 御剑飞行 | 特殊玩法流派 |

> **构筑逻辑**：装备决定「招式」和基础数值，技能槽位（主动）+ 词条（被动）决定「怎么打」。同一套装备 + 不同技能 = 不同打法。**用少量装备 × 大量技能组合，代替几百件装备**，解决内容消耗问题。

## 装备 / 资源系统（暗黑式）

### 装备

| 槽位 | 说明 |
|------|------|
| 武器 | 决定招式流派 + 基础攻击 |
| 防具（衣/护腕/靴） | 防御 + 词条 |
| 饰品（戒指/玉佩） | 词条为主 |
| 法宝 | 主动技能载体 |

- **品质**：白 / 绿 / 蓝 / 紫 / 金（Diablo 同款，金色带专属特效）
- **词条随机**：攻击、暴击、吸血、减 CD、元素伤害等
- **掉落**：普通怪掉白绿蓝，精英掉蓝紫，Boss 掉紫金

| 资源 | 用途 |
|------|------|
| 灵石 | 货币（买药、强化） |
| 修为/经验 | 等级成长 |
| 丹药 | 回血/回蓝/临时 Buff |
| 功法残页 | 解锁新技能 |
| 材料 | 强化装备/合成 |

## 剧情系统（大表哥式对话推进）

- 剧情通过**触发 NPC 对话**推进，不做强制过场
- 玩家自由探索，走到关键 NPC/地点触发对话，推进主线
- 对话中可解锁新地图、新技能、新任务
- 结构：**主线（关键 NPC）+ 支线（世界里的散落 NPC/事件）**

> 设计要点：剧情是「探索的奖励」而非「强制引导」。玩家想推剧情就去找 NPC，想刷装备就继续打怪，自由度归玩家。

## 视角 / 技术实现（Godot 4）

### 等距 3/4 怎么做（纯 2D）

| 技术点 | Godot 实现 |
|--------|-----------|
| 地面 | `TileMapLayer` + 等距 tile（或程序化画等距网格） |
| 角色 | `Sprite2D` + 3/4 视角精灵（全身可见） |
| 深度排序 | `y_sort_enabled = true`——按 Y 坐标决定前后遮挡 |
| 移动 | 八方向 XY 移动，输入映射到等距轴 |
| 碰撞 | `CharacterBody2D` + 圆形/胶囊碰撞体 |
| 攻击判定 | `Area2D` 近战判定框（旧 bullet 层改造） |
| 摄像机 | `Camera2D` 跟随，可加视差背景 |

### 打击感四要素（0 素材成本，沿用旧设计）

| 要素 | 做法 | 成本 |
|------|------|------|
| 屏幕震动 | Camera2D offset Tween，重击 4px 轻击 1px | 0 |
| 击停帧 | 命中瞬间双方暂停 0.05-0.1s | 0 |
| 粒子特效 | 命中火花、剑气拖尾、受击碎片 | 0（程序化） |
| 音效 | 挥剑/命中/格挡/死亡声 | 需素材 |

### 人工验收（自检证明不了，必须 F5）

自检能验「相位会推进」「能打到人」，但验不了**手感**。下列 6 条必须自己跑：

1. **起手看得清吗？** —— 敌人挥砍前能不能明确看出「它要打了」，并据此按下格挡
2. **精准格挡有回报感吗？** —— 金色爆闪 + 敌人硬直，是不是立刻想反打
3. **鼠标瞄准顺手吗？** —— 举盾时用鼠标转身，正面挡/背后挨打是否符合直觉
4. **精力逼出取舍了吗？** —— 是否出现过「想闪但精力不够」的时刻
5. **蓄力值得吗？** —— 满蓄破霸体那一刀，是否比连点轻击更爽
6. **破防够痛吗？** —— 精力见底被打崩，是否让你下次不敢硬挡

## 设计原则

1. **玩法第一** — 手感调好了再加美术和内容
2. **纯代码先行** — 原型不需要外部素材，`_draw()` 几何图形验证
3. **资源是灵魂** — 仙侠的爽点是「积累变强」，掉落和成长要做好
4. **操作高频 + 反馈强** — 精力系统 + 打击感 > 招式数量
5. **少装备多组合** — 用技能构筑代替海量装备，省内容
6. **可测试** — 任何时候 F5 都能跑
7. **边做边写文档** — 脚本标注学习文档引用，双向关联
