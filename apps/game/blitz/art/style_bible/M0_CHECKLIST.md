## 0.5 AI 优先路线（可以跳过 §1 的收集）

如果不想花几小时翻参考图，可以**直接用 AI 生成 3 张锚图**，它们替代 §1 的「3 张锚图」。
但锚图不是终点——它必须先过「像素网格 + 色数 + 剪影」检查，才有资格当锚。

### 三张锚图

| 文件 | 定什么 | 存到 |
|---|---|---|
| `anchor_character.png` | 主角比例、服装、描边、明度 | `references/characters/` |
| `anchor_environment.png` | 地砖、悬崖边、光照方向、色温 | `references/environment/` |
| `anchor_ui.png` | 边框厚度、圆角、语义色、字体样张 | `references/ui/` |

### 流程

1. 接 MCP（首选 Retro Diffusion，命令见 [MCP_SETUP.md](../MCP_SETUP.md)）
2. 按 [prompts.md §8](prompts.md) 锁参数：模型 / style / seed / 分辨率 / prompt / negative prompt
3. 每类生成 **6 张候选**，只挑 1 张
4. 过 [prompts.md §9](prompts.md)：`fix_pixel_art` → 量化到 `palette.gpl` → 1px 描边 → 1× 检查
5. 把选中的 3 张存进 `references/`，**它们就是后续所有生成的锚图**
6. 之后所有生成都带锚图（IP-Adapter / img2img / style reference），不要从零 prompt

- [ ] 3 张锚图生成完毕
- [ ] 每张都过了像素网格 / 色数 / 剪影检查
- [ ] 参数记录在生成日志里（模型、style、seed、prompt）
- [ ] 后续生成全部带锚图

> **两条边界**：
> 1. 生成模型**读不了 `.gpl`**，调色板必须靠 prompt 写 hex 或生成后量化（见 [prompts.md §10](prompts.md)）。
> 2. **UI 最终不要用生成模型出。** 锚图只定概念，9-slice 和图标在 Aseprite 里重画一遍。

- [ ] 字体样张（12px / 16px）

### 3B. 环境小样（第一张地图：夜寺）

- [ ] 4×4 地砖（每块 32×32），拼起来检查接缝

## 4. 3D→像素小样（3~4 小时）

**先不建模主角**，用一个胶囊 / 人形 proxy 验证「3D 渲出来能不能贴像素风」。

### Blender 设置（关键）

| 项 | 值 | 原因 |
|---|---|---|
| 单位 | **1 Blender unit = 1 美术像素** | 像素密度直接可算 |
| 角色高 | 112 units | 和规格表一致 |
| 相机 | Orthographic，`ortho_scale = 192` | 画布 192×192，角色占 112 |
| 机位 | yaw 0°，pitch 0~5° | 和像素资产一致 |
| 背景 | Film → Transparent | 透明导出 |
| 抗锯齿 | 关（Eevee TAA samples = 1） | 不要软边 |
| 色彩管理 | View Transform = **Standard**，Look = None | AgX/Filmic 会让颜色偏，量化对不上 |
| 光照 | 左上主光 + 弱补光，toon 3 阶 | 和像素高光方向一致 |

- [ ] 搭好相机和灯光
- [ ] 材质用 toon（Shader to RGB → ColorRamp 3 档）
- [ ] 渲 192×192 PNG（RGBA）
- [ ] 进 Aseprite：Image → Color Mode → Indexed，载入 `palette.gpl`
- [ ] 加 1px 深色描边
- [ ] 和 §3 的像素小样并排看

**判定**：如果 3D 小样看起来像「缩小的 3D 模型」而不是像素画，先调这三处：
1. 降分辨率 / 提高 toon 阶数对比
2. 减少材质细节，让色块更大
3. 描边加粗到 1px 并统一颜色

## 5. 风格锚定图（4~6 小时）

**这是 M0 唯一必须交付的成品。** 1280×720，1×，不缩放。

- [ ] 背景：1 层视差（远山 / 建筑剪影）
- [ ] 地面：一段不规则边缘（用掩码的阶梯边 + 悬崖砖盖住）
- [ ] 玩家 idle（112px）
- [ ] 小兵（80px）
- [ ] 1 个道具
- [ ] 刀光 1 帧 + 雷击 1 帧
- [ ] HP / 气力 / 蓝条 + 3 个技能图标
- [ ] 1× 截图检查
- [ ] 模拟全屏 1.5× 检查（放大 150% 看一眼）

**构图建议**：玩家放画面左 1/3，小兵在右 1/3，中间留出战斗空间；
地面边缘放在下 1/3，背景占上 1/3。这样一眼能看出「这是游戏画面」，不是插画。

## 6. 签收（30 分钟）

- [ ] **剪影测试**：把玩家 / 小兵 / Boss 填成纯黑，能一眼分辨
- [ ] **3 秒测试**：看一眼，能找到玩家、危险、可交互物
- [ ] **并排测试**：3D 小样和像素小样放一起，不像两个世界
- [ ] **1.5× 测试**：放大后没有明显的糊边 / 断裂
- [ ] 把最终数字回填 `rules.md`
- [ ] 保存 `style_plate_v1.png` 和源文件（`.aseprite` / `.blend`）
- [ ] **冻结**：M2 / M3 管线跑通前，不再改风格

## 判定标准（过不了就重做对应步骤）

| 检查 | 通过标准 |
|---|---|
| 剪影 | 纯黑下，玩家 / 小兵 / Boss 轮廓不同 |
| 可读性 | 1× 下 3 秒内找到玩家和危险 |
| 调色 | 所有颜色来自 `palette.gpl`，没有额外色 |
| 光照 | 所有资产高光都在左上 |
| 描边 | 1px，颜色统一，不是纯黑 |
| 3D 融合 | 3D 小样和像素小样并排无明显割裂 |
| 全屏 | 1.5× 下仍可读，没有明显糊边 |
