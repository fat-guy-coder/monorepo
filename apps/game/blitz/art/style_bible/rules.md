# Blitz 风格锚（M0 锁死项）

> 这些数字一旦定下，**所有资产都按它做**。改一个，全部返工。
> 先按这份执行；M2 / M3 的管线验证跑通后，再把实测结论回填到这里。

---

## 0. 一致性的边界：UI 锁死，地图换色

> 2026-10-23 定：**UI 是唯一常量，地图允许按区域换色。**

### 0.1 全局核心（所有地图都不变）

- UI：边框、字体、图标网格、语义色
- 玩家 / 小兵 / Boss 的角色配色
- 所有 VFX 的主色
- 描边色系、光源方向、明暗档数

### 0.2 每个区域可以换的

- 地面 / 墙面 / 背景 / 道具的环境色
- 天气、雾气、环境光偏色
- 每个区域 8~12 个环境色，不进入核心调色板

### 0.3 换色时必须守住的可读性

| 规则 | 原因 |
|---|---|
| 可走地面永远比虚空亮 | 玩家要一眼看出哪里能走 |
| 危险 / 敌方预警永远用朱砂红 | 红不能拿去装饰 |
| 奖励 / 可交互永远用鎏金 | 金不能拿去当普通墙色 |
| 角色明度永远高于背景 | 换到雪地 / 沙漠也要能看清 |
| 描边永远是同一族深色（不是纯黑） | 跨区域保持同一套轮廓语言 |
| 高光永远在左上 | 光源方向不能随地图变 |

### 0.4 UI 契约（一致性真正落在这里）

| 项 | 规则 |
|---|---|
| 边框 | 同一套 9-slice，圆角 / 直角、厚度、描边完全一致 |
| 字体 | 同一套像素字体，12px / 16px 两档 |
| 图标 | 48×48 网格，同样的内边距和描边 |
| 语义色 | HP 红 / 气力黄 / 蓝条青 / 危险红 / 奖励金 |
| 状态 | 正常 / 低 / 锁定 / 冷却，四态的画法一致 |
| 动效 | 条填充速度、受击闪白、低血暗角用同一套参数 |

> UI 不需要跟地图换色。它悬浮在屏幕最上层，是玩家跨区域唯一稳定的视觉锚点。

## 1. 画面

| 项 | 值 | 说明 |
|---|---|---|
| 设计分辨率 | 1280×720 | 全屏后按屏幕比例 `expand` |
| 像素密度 | 1 美术像素 = 1 设计像素 | 不缩放素材；缩放交给引擎 |
| 纹理过滤 | Nearest | 禁止线性过滤 |
| 抗锯齿 | 禁止 | 3D 渲染和像素绘制都不开 |
| 相机 | 正交侧视 | Camera2D zoom = 1 |
| 机位 | yaw 0°，pitch 0~5° | 全项目锁死；想改机位 = 全部重渲 |
| 地面纵深 | ≤ 18 格（576px） | 超过相机就会上下滚 |

> 全屏拉伸：`canvas_items` + `expand`。1080p 是 1.5×，1440p / 4K 是整数倍。
> 如果最终不能接受 1.5×，再考虑把设计分辨率提到 1920×1080（角色按约 168px 重画）。

## 2. 角色尺寸

| 角色 | 身高 | 画布 | 说明 |
|---|---|---|---|
| 玩家 | 112px | 192×192 | 画布留出挥砍空间 |
| 小兵 | 80px | 128×128 | |
| Boss | 192px | 320×320 | |

- **枢轴 = 脚底中点**。在 Godot 里 `AnimatedSprite2D.centered = false`，
  `offset = (-画布宽/2, -画布高)`，让脚底落在 `(0, 0)`。
- 角色在画布里**水平居中、脚底贴底**；挥砍/施法可以短暂超出身体，但不要超出画布。
- 画布尺寸只增不减：后面要做更大范围的招式，直接换更大的画布，不要缩放。

## 3. 调色与光照

| 项 | 规则 |
|---|---|
| 调色板 | 核心 32~48 色，见 `palette.gpl`；UI / 角色 / VFX 必须用它 |
| 光源 | 固定**左上**主光 + 右下弱补光 |
| 明暗 | 3 档以内（亮 / 中 / 暗），不要连续渐变 |
| 描边 | 1px 深色轮廓（不是纯黑，用调色板里的深色） |
| 高光 | 1px，只放在受光边缘 |
| 禁用 | 抗锯齿、渐变、软阴影、半透明羽化、噪点纹理 |

> **调色板分两层**：核心色（§0.1，所有地图共用）和区域环境色（§0.2，每个地图 8~12 色）。
> 当前 `palette.gpl` 是「核心 + 第一个区域（夜寺）」的并集；
> 做第二张地图时另建 `palette_region_02.gpl`，不要往核心色里塞新颜色。

> 3D 渲染结果必须量化到 `palette.gpl`，再补 1px 轮廓。
> 否则连续色阶会和手绘像素场景「两个世界」。

## 4. 动画

| 项 | 规则 |
|---|---|
| 帧率 | idle / walk 10~12 fps；攻击 24 fps；死亡 12 fps |
| 动画 | **原地**，不烘根位移 |
| 命中帧 | 写进 manifest；和 `AttackHitbox` 生成时刻对齐 |
| 朝向 | 纯侧视只做朝右，`flip_h` 镜像；若改 ±12° 双角度则两套都渲 |
| 跳跃 | 只做姿态，竖直位移由代码的 `height` 管 |
| 接触阴影 | 独立节点，不烘焙进帧 |
| 过渡 | 不依赖动画混合；状态机切换 + 单帧过渡即可 |

**攻击时长（要重调）**：

| 动作 | 目标时长 | 命中帧 |
|---|---|---|
| 玩家轻击 | 0.28~0.32s | 第 3 帧 @24fps |
| 玩家重击 | 0.45~0.55s | 第 7 帧 @24fps |
| 小兵横扫 | 保持现有三段时序 | 第 4 帧 |
| 小兵纵劈 | 保持现有三段时序 | 第 5 帧 |

> 现有轻击 0.15s 撑不住 7 帧动画。先改时序，再让动画去对齐。

## 5. 3D 渲染设置（Blender）

| 项 | 值 |
|---|---|
| 相机 | Orthographic，固定机位 |
| 输出 | 画布尺寸 = 角色画布（192/128/320） |
| 分辨率 | 1×，不超采样 |
| 背景 | Transparent Film |
| 抗锯齿 | Off |
| 光照 | 固定左上主光 + 补光，3 档 toon |
| 阴影 | 不渲投影（接触阴影单独做） |
| 导出 | PNG 序列 + manifest |
| 后处理 | 调色板量化 + 1px 轮廓，脚本化 |

**模型 / 绑骨**：

- 干净的 base mesh 优先；AI 生成拓扑要预留清理时间。
- 衣摆 / 披风 / 长发加骨骼链，避免穿模。
- 自动绑骨（AccuRig / Mixamo）后必须人眼检查权重。
- 武器作为独立骨骼挂点，方便换武器重渲。

## 6. 像素资产规则

- 地砖 32×32；Blitz 的一格 = 64×32 屏幕像素 = 2×1 块砖。
- 地砖必须有**边缘 / 拐角**变体，用来盖住掩码的阶梯边。
- 道具按 32×32 网格摆放；底部中点作锚点。
- VFX 用加法混合（发光物），但颜色仍取自调色板。
- UI 用 9-slice；图标 48×48；字体 12/16px。
- 预警 / 调试面板**保持矢量**，不做像素帧。

---

## 7. 禁用清单

- ❌ 抗锯齿 / 线性过滤 / mipmap
- ❌ 连续渐变、软边阴影、高斯模糊
- ❌ 把接触阴影烘焙进角色帧
- ❌ 手改 `art/export/` 里的导出图
- ❌ 一个角色混两条管线
- ❌ 缩放素材来凑尺寸（要改就重渲 / 重画）
- ❌ 在 1× 下看不清的 1px 细节（全屏 1.5× 会更糊）
